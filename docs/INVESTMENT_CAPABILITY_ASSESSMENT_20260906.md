日期：2026-09-06。性质：调研、当前代码核验、隔离开发复现与推进建议；不是策略晋级、生产接入或 roadmap 变更。

## 结论与目标

项目应保留两个同时成立的目标：**从部分到完全授权的可信自动化交易是基本能力；同时改善费用后收益、回撤和尾部风险是投资有效性目标。** 研究助手、逐笔审批和自动下单只是功能子集。某个算法不能带来增量时，应调整其职责，不因此降低整个产品目标。

本轮建议采用“现有 Harness + 可复现策略基准 + 有界策略/特征工具”的方向继续验证。优先验证简单价格规则；隔离的 Qlib 特征计算作为进一步候选，是否接入取决于实际特征/模型需求；FinRL 生态可提供算法、训练环境与权重接口的参考，但本轮证据不足以接纳其训练模型、整体交易框架或收益宣称。**算法可以复用，账户、授权、风险和执行的权威不能随库迁移。**

需要同步推进两条验收线：一条补齐可信自动化闭环，另一条证明投资增量。宽基 H5 预测不能成为行业选股和持仓管理的通用替代指标；短期工程复现也不能代替正式收益风险验收。

本轮没有新增付费模型调用、市场数据购买、训练任务或券商操作。现有源码、roadmap、历史签名和已冻结预测保持原样。授权的隔离研究脚本、依赖和许可数据衍生物存于忽略目录；本报告只公开汇总。

### 新闻故障的精确诊断

对本次保存的原始响应进行只读散列检查和现行解析器重放：共三页，每页 1,000 行，共 2,999 条不同的完整行；第三页有一条完全相同的重复行，未发现其他跨页重复。三页原始内容散列均通过。

来源主键是 `(datetime,title,content)`，响应还含 `channels`。`tushare_observation.py` 的页级主键校验只有在主键字段元组等于全部响应字段元组时才容忍重复，因此本次相同行仍产生 `duplicate_primary_key`。页 1、2 通过，页 3 重现失败；第三页原始数据保存后采集中断，失败结果公开零条规范化 observation。

最小修复建议：仅为明确的新闻来源定义完全相同记录的去重语义，保留原始页和原有身份；同主键但内容不同仍拒绝，页内与跨页规则一致。需要验证相同重复、冲突重复、原始数据留存和 PIT 身份。**第三页仍是满页，第四页从未采集；去重旧三页不能证明覆盖完整。** 原始失败和已冻结价格预测必须保持不变；修复后的采集产生新收件快照。

## 3. 隔离复现

选择清单在候选运行前固定：一个 TA-Lib SMA5/20 长仓/现金规则，一个 Qlib Alpha158 close-only 特征子集；RL 第三个名额要求先找到合格训练工件，未满足则保留空缺。没有用随机策略占位，也没有发起完整训练。

三个窗口固定为 2015 去杠杆、2018 熊市、2024 政策上涨，均为此前打开过的开发样本，分别有 52、120、6 个注册交易日。它们属于 `opened_historical_modeled_pit`，未通过 Strict-PIT 验收；用于工程、经济口径和失败诊断，不是新的未知样本，也不是对未来表现的证明。窗口缺失时仍保留分母，不根据收益更换。

### Qlib 原生特征复现

输入属于已打开历史数据的 Modeled-PIT，`strict_pit_accepted=false`；按交易日过滤与复权口径构造前缀，并未证明这些历史数据版本在当时已经真实收件。前缀不变检查验证计算不会受追加未来价格影响，不能升级为历史可获得性证明。

在每个窗口首个决策截止点重开最多 252 条按上述模型可见的收盘记录，生成 ROC、MA、STD 的 5/20/60 日配置，共九个特征。使用官方 Qlib 原生表达式引擎和固定版本数据导出脚本，不用本地替代公式冒充原生实现。

每个窗口分别运行截止点前缀、追加后续实际价格、将后续价格放大 100 倍三种数据视图；截止点特征散列保持相同。独立数值计算的最大绝对误差小于 `6e-8`。未来表达式、未来请求、预热不足、缺行、缺价格和输入散列篡改有针对性检查。ROC 在此库的定义是 `previous/current`，不能直接当作 `current/previous-1` 的收益率解释。

这证明九个特征及进程隔离的可行性，不证明完整 Alpha158、股票横截面因子收益、训练模型质量或 Agent 实际使用效果。根据本轮环境占用与隔离成本，仅需要这些基础指标时应优先复用 TA-Lib 等较轻的指标库；九个特征跑通本身不是生产引入 Qlib 完整依赖的理由。没有新模型调用，经济收益为不适用；不是零收益。

上述为共同隔夜半仓建仓后 NAV 起算的费用后描述收益；“转现金”包含首个可成交开盘的卖出及费用，因此不必恰为零。完整 30 条收益、最大回撤、日 CVaR95、Sharpe/Sortino、换手、费用及平均资金占用见[账户统计](research/investment-assessment-20260906/account-results.md)。

没有出现一致的收益与风险共同改善：2015 年 SMA 相对保持半仓的收益几乎相同，但日 CVaR95 为 -7.31%，比半仓的 -4.21% 更差；2018 年 SMA 收益为 -6.94%，不及既有三日动量的 -2.58%；2024 年 SMA 比同条件宽基少赚 5.43 个百分点，平均资金占用为 65.01%，宽基为 96.33%。三个窗口的经验 5% 尾部只相当于 2.6、6、0.3 个交易日，不能声称可靠尾部风险估计。

结论是 SMA 可以进入后续固定基准/指标工具候选，不能因此晋级为收益策略。这些结果没有检验 Agent 使用指标、选择策略或加入事件信息的增量，也没有否定完整自动化产品目标。首次共享目录散列审计失败及后续收窄检查另行保留；没有新增付费模型、源请求或券商访问。

## 4. 如何集成与怎样验证增量

三种角色必须分别评价：独立基准、Agent 只读工具、Agent 策略选择/组合。即使某个固定策略表现好，也不能推导 Agent 选择它的时机正确。

最小接口草案只沿用已有研究/组合路径：

1. Harness 绑定只读快照、目标、截止时间和已注册 recipe/model 版本。特征工具仅计算需求所需历史字段；训练标签留在研究评价侧。
2. 外部实现返回特征或分数，附单位/方向、适用条件、数据与计算版本、缺失状态。来源、身份和可推导引用由 Harness 注入，不要求模型重复长 ID。
3. 若算法输出目标权重，先明确它是全账户权重、活跃子集权重还是持仓增量，并保留现金项；只有语义完全匹配时才作为现有组合建议输入，不静默归一化或截断负权重。
4. Agent 可以读取授权账户视图并给出经济建议；不能改写账户权威、凭证、最终数量或执行权限。策略的买入意见不意味着必须买入：已有集中持仓可能应减仓。
5. Harness 继续拥有确定性 sizing、授权、风险、Nautilus 执行、未知回执和对账。周期复核由现有入口接续，外部工具不自启后台交易。

未知特征不变成零信号或现金指令；缺少账户权威仍是未完成。过期、越界训练截止时间、不相容动作或不完整证券映射返回明确缺口。源已变更时建立新输入，不给旧建议补写许可。本轮没有新增公共接口。

后续先以固定策略为完整账户基准，逐项加入：Agent 使用同一策略工具、事件证据、动态候选、持续复核。每一步冻结其他条件。选择器同时比较固定单策略和只用过去信息的确定性切换；禁止事后行情标签选择赢家。开发数据选择最强可部署主基准后冻结，再进入未知样本。[S17]

正式成功标准保持 [Agent Effectiveness Acceptance](AGENT_EFFECTIVENESS_ACCEPTANCE.md#balanced-acceptance-gate)：完整 24-case Strict-PIT holdout 与另行注册的前瞻项目分开；前瞻至少 30 个真实收件事件簇、20 个非空执行和四种市场状态。还需通过费用后超额的统计下界、回撤/CVaR 相对约束、Sharpe/Sortino、加倍费用、下跌保护与事件/状态移除稳健性要求。这些数量是当前注册最低门槛，不是任何策略达到相同数量就自动可靠。

复核所有经济比较的同初态、外部现金流、资金上限、T+1、整手、限价/停牌和公司行动。日线不能构造网格的日内交易路径。固定资金与新增定投资金分开比较，报告资金加权与时间加权结果及资本占用，不能只对比终值。未知、无成交、失败与缺失留在报告中。

## 5. 对后续 roadmap 的建议（尚未修改）

| 决策 | 建议及验收结果 | 粗略投入判断 |
|---|---|---|
| 保留 | Harness/pi/Nautilus 权威分工、完整自动化目标、收益/回撤/尾部联合验收 | 不重建框架；继续复用已有组件 |
| 优先补齐：数据 | 来源范围内相同新闻去重、冲突拒绝、分页终止及真实新快照；整理预期、公司暴露与 PIT 数据缺口 | 小到中等实现量；需真实新采集证据，不能以旧页修补替代 |
| 优先补齐：基准/工具 | 给现有账户补充少量预注册价格规则；明确指标语义与只读工具投影，再验证 Agent 工具使用 | 中等实现量；本轮复现降低算法/引擎适配不确定性，不包含正式模型费用估计 |
| 并行补齐：可信自动化 | 在已有自主 owner 下完成周期复核到执行/对账的组合验收；先本地明确 Mandate 内的全授权闭环，再分别真实 Paper 场景及撤销/恢复 | 中到高；主要约束是运行证据和外部场景可达性，不是再写一个执行引擎 |
| 下一投资实验 | 选择一个业务传导清楚且源足够的事件族，完整账户对照；把事件、选股、复核贡献分开 | 需按实际输入字节、完整组数和模型路由重新估费；本轮不动用旧预算 |
| 推迟 | 大规模 RL 训练、因子挖掘、多模型矩阵、日内网格、未经 PIT 证明的戴维斯双击选股 | 数据/环境/训练工件未过门槛；扩大规模目前不能解决可归因性 |
| 暂不采用 | 整体迁移 FinRL-X/Qlib 的账户与执行栈、无训练清单的 actor、以回测图作为准入凭据 | 避免第二权威、历史数据泄漏和不可复现状态 |

投入等级是本轮代码与依赖核验后的规划判断，不是交付工期承诺。当前新增模型/数据/券商费用均为零，后续费用不能从两个研究窗口简单外推；应先冻结完整配对组和上下文规模。机器存储与本地计算消耗另列附件。历史工程和实验投入不与本次成本混同。

本报告支持继续验证上述架构与候选，不支持降低成功标准或直接交易。如果后续完整对照没有增量，应缩小或替换算法职责，保留全自动化产品目标与原有安全边界。
