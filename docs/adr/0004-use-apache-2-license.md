# ADR 0004: Use the Apache License 2.0

- Status: Accepted
- Date: 2026-08-26

The initial AGPL license made network use reciprocal even though this project needs broad
composition with permissively licensed Agent, MCP, data-adapter, and trading-engine
components. Re-license first-party code to Apache-2.0 to retain a permissive grant with
explicit patent terms and notice requirements. Third-party code remains under its own
license, and this decision grants no right to redistribute licensed financial data, news,
model weights, or API content.
