# ADR 0005: Gate prospective accrual on frozen source coverage

- Status: Accepted
- Date: 2026-08-26

A first-eligible prospective cohort cannot be audited if whichever source happened to be
implemented first silently defines the event universe. Before accrual opens, freeze a
Source Coverage Registration and require a complete Coverage Receipt alongside every
potentially qualifying Candidate Event Observation. Discovery sources may find candidates
and official or directly involved primary sources may establish occurrence facts, but a
failed mandatory source blocks admission rather than shrinking the observable universe.

This does not claim exhaustive global news coverage. It makes the monitored universe,
cadence, blind spots, and degradation periods explicit so later evaluation cannot mistake a
single-source convenience sample for the registered first-eligible cohort.
