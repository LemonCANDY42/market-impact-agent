# Numerical method screening, 2026-09-08

This is a bounded primary-source screening for the single RTX 5090 experiment, not a global leaderboard or an independent reproduction of paper returns.

| Candidate | Primary evidence | Practical decision |
| --- | --- | --- |
| Qlib Alpha158 + linear / LightGBM | Maintained [official implementation](https://github.com/microsoft/qlib), pinned `79633dd9506ea689e5400dea0197717b5b3d74b7`; this round reproduced positive CSI300 research diagnostics, with strict-boundary and cost sensitivity | Keep both as numerical baselines. Expand universe/history and compare structured feature tiers before adding text. |
| AlphaGen LSTM / Transformer | [Official repository](https://github.com/ICT-FinD-Lab/alphagen), pinned `259687e8f316994426416c530a94842a2fe6405e`; KDD 2023 method, current repository also contains TransformerSharedNet and CUDA-capable factor calculations | Run a larger, matched GPU experiment with the maintained operators/pool/PPO and a caller-level temporal/data adapter. The completed 4,096-action CPU pilot failed its historical test; it neither establishes effectiveness nor rules out larger experiments. |
| HARLA | Same authors' [publisher paper](https://journal.hep.com.cn/fcs/EN/10.1007/s11704-025-41061-5) and the AlphaGen repository's `scripts/rl.py`; 2026 volume, online publication in 2025; alternates learned expression search and LLM-assisted pool updates | More recent than AlphaGen, but adds LLM search assistance, not demonstrated news information. Upstream callback reads test scores each rollout and the example chat client names an external endpoint. Reuse algorithms with held-out feedback withheld and an explicitly local client if that branch is tested. Do not execute the example's endpoint or selection workflow blindly. |
| AlphaForge | [AAAI 2025 official repository](https://github.com/DulyHao/AlphaForge), pinned `d0cfc27df23c60f271bc885fd43027b86b787746` (latest commit 2024-09-01); neural generator/predictor and dynamic factor combination | Technically GPU-oriented and worth comparison. Source uses a CNN predictor / DCGAN generator, not a Transformer. Default mining continues until the factor zoo fills, so a bounded training-only compute protocol is needed before execution. Dynamic combination explicitly shifts its 20-day target feedback by 21 days. No repository license was detected by GitHub API; keep source in private research storage, do not vendor it into the project or represent it as licensed production code. |
| AlphaPROBE | [February 2026 preprint](https://arxiv.org/abs/2602.11917) and [author code](https://github.com/gta0804/AlphaPROBE) | DAG-based factor evolution with Bayesian retrieval; interesting search diversity direction, with author-reported results across three Chinese stock datasets. Preprint recency and reported gains do not establish superiority for this data or justify replacing the measured baseline. |
| AlphaBench | [ICLR 2026 author paper](https://www.cs.cityu.edu.hk/~cliu644/HomePage/doc/AlphaBench/AlphaBench_PDF.pdf), especially task definitions and evaluation limitations | Useful for separating factor generation, evaluation and search. It reports persistent robustness and calibration weaknesses; an LLM's verbal judgment is not the numerical factor acceptance oracle. |

The immediate experiment prioritizes transparent supervised baselines and the maintained AlphaGen Transformer/LSTM comparison. HARLA/AlphaForge remain conditional extensions after data and throughput checks; their existence is not evidence that they will outperform. The user authorized stronger/larger GPU models, but model size is not the selection criterion. No paid model calls or broker execution are involved.
