evidence produced no additional correct H5 judgment.** One independent reviewer
preferred Luna in all four blinded pairs, modestly or narrowly, with no material
unsupported fact found across the eight outputs from both models. Luna had more concrete
price observations and counter-tests. Its February event answer still left the

it does not justify an unattended investment default or a blanket switch for

The panel retains two evidence arms, two models and eight serial counterbalanced
Runs. Only the event arm receives the bound official source. All Runs, including
failures and unknown directions, remain in the denominator. H5 is primary; H1 is
a diagnostic of the same forecast. The existing cutoff-only 20-return volatility
band defines rangebound outcomes. A separate frozen baseline compares the aggregate
20-session adjusted return with that H5 band. This is one simple comparator, not an
optimized or comprehensive baseline suite.

Blinded source review precedes model/cost/outcome unblinding, using the original
five-criterion rubric. Promotion requires all four Luna Runs to complete, no material
unsupported facts or loss of reasoning quality, and lower observed cost. Direction
hits cannot override the grounding gate. Two new windows cannot establish model
non-inferiority or investment effectiveness.

## Input corrections

Prices retain their original quotes and adjustment proof, with an explicit consistent
adjusted-close basis for return comparisons. Metadata separates exact publication,
modeled date-only boundary, availability, occurrence, effective date and receipt.
Unknown source times remain absent. The prompt distinguishes stated facts from
hypothesized mechanisms and requires priced-in claims to be identified as hypotheses
when no expectations evidence exists. Previous pilot artifacts remain immutable;
these corrections are not a retroactive reclassification of its failures.

The original preparation's reversal label is no longer a universal admission rule:
requiring a known reversal would force outcome-based selection in a source-first
follow-up. All source, cutoff, calendar, horizon and budget gates remain in place.
Verified CSRC supplements are bound by the execution registration; the intermediate
price preparation alone intentionally reports missing event evidence.

The first eight native Runs failed before any physical model request because the
operator invoked the CLI without the project's configured model environment.
All eight remain signed `incomplete / RuntimeError` terminals with zero requests,
zero tokens and zero cost. This is an operator startup failure, not evidence about
either model's analysis. The original panel report remains unchanged.

The explicit infrastructure companion permits exactly one fixed successor Run ID
per original member. It verifies the original registration, native report/terminals,

member allowances. It creates no new budget group, releases no allocation, and
replays the same successor on restart. Inputs, profiles, prompt and serial order
remain frozen. Any successor failure is retained; no semantic retries are allowed.
Original startup failures and recovered research completion must be reported
separately rather than silently replacing the denominator.

For subsequent launches, run the existing read-only runtime doctor in the same
configured environment as the experiment and check credential-presence booleans.
An accepted runtime permit and passing source checks do not establish that the
current launcher actually supplied the required credential environment.
