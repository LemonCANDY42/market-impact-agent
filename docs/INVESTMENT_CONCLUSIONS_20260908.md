# 实验综合评估与取舍：2026-09-08

性质：综合已完成实验，并对冻结账户补做事后路径诊断。不是策略晋级、正式 roadmap 修改或新一轮训练授权。后续改动使用已经打开的 2025–2026 年样本时，必须标为开发或诊断。

## 判断

当前值得保留的是已有 Harness、27B 文档提取候选，以及 LightGBM-B 的横截面排序信号。**尚无通过项目经济验收的自动投资策略；当前 Top50/drop5 组合不符合改善收益与回撤的目标。** Agent 的自主仓位管理、新闻投资增量和学习搜索的预算匹配优势均未被证明。自动化交易的产品目标保留，具体算法职责可以被淘汰。

本轮投资研究的优先级应从扩大模型种类，转向识别“排序分数如何成为可接受的账户结果”。这不预设问题全部在风控层：全市场排序相关性不能说明前 50 名是否具有可实现的绝对收益，也不能排除共同风格暴露或持仓规则的问题。

同峰谷列是指数在策略自身峰谷期间的累计收益，不是指数自己的最大回撤。整个 2025-01-03 至 2026-08-31 账户区间，CSI300 复利收益约 21.06%，最大回撤约 10.49%。它是全市场选股的背景基准，不是风险暴露匹配基准，以上差距不能直接归因为选股 alpha 损失。

三种子双倍成本账户日收益相关性为 0.9494–0.9615，最大回撤谷底相同。基础成本下的大回撤仍在，说明当前结果不能用“只是双倍费用过高”或“只是一个种子倒霉”解释。基础与双倍成本是分别运行的账户，成本会改变后续资金与持仓；两者差额不能全算作纯手续费拖累，基础成本回撤也不必机械地更小。

三种子平均实际股票仓位为 71.53%–78.07%，不能描述成始终满仓或始终 95% 仓位。各自回撤区间内的全市场 RankIC 均值仍为正，约 0.0684–0.1085。这是对应特征日的前向五日排序相关性，不是同日持仓损益解释，也不证明前 50 名组合在该区间有正 alpha。

在已测三个种子之间挑选不能解决大回撤，基础成本结果也排除了“仅双倍费用造成大回撤”的解释；尚不能区分前列信号失效、行业/市值/Beta 暴露、退出与换手规则、流动性或退市数据问题。需要持仓与成交级归因才能判断各部分贡献。本次未完成该层归因。

## 推进次序与停止条件

1. **先解释当前账户损失。** 用保存的持仓/成交和预测，分解亏损集中度、前 50 名与全横截面表现、行业/规模/Beta 暴露、换手费用及退出/重新入场。缺失持仓证据时明确缺口，不能仅凭净值曲线命名原因。此阶段沿用冻结预测，不重训。
2. **建立与问题相符的简单组合对照。** 归因后只选一个主要改动，保持信号、可见数据、资金和执行口径相同；同时保留原组合、可部署机械基准和现金/暴露背景。降低仓位带来的回撤缩小必须同时报告少赚的上涨、费用和资金占用，不能单看回撤宣布改善。
3. **再隔离 Agent 的账户管理贡献。** 若简单组合已有值得继续的经济表现，比较相同数值信号、市场/账户信息、交易权限、硬限制和费用下的机械决策与 Agent 复核。先不加入新闻变量。Agent 需证明持仓调整的经济价值，包括退出和重新入场，而非仅提供解释。
4. **新闻另做配对。** 上一步有保留 Agent 决策职责的理由后，再比较同一 Agent 有/无事件证据。新增历史新闻只能作探索；严格增量验收使用满足原门槛的未知样本/真实收件证据。文档提取正确率不代替这项验证。

每一步优先少量完整配对并冻结主要比较，按现有收益、回撤、尾部、成本与稳健性门槛决定是否扩大；不在看到结果后换最有利指标。开发诊断可以提前排除明显无价值方案，但不能拿小样本宣布稳定胜出。当前无需增加服务、框架、第二执行引擎或模型矩阵。

若简单组合修正仍无经济价值，暂留数值模型为研究工具，停止围绕当前策略扩大投入。若 Agent 管理不增加价值，取消这一算法职责，保留证据提取/研究用途。自动化产品目标以及已有授权、风险、对账边界不因此降低。
