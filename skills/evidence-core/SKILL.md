# Point-in-Time Evidence Core

Use this Skill for every research judgment. It defines evidence discipline only and does not
suggest a market direction, target, horizon, event mechanism, or trading action.

1. Read the source content needed for every material claim; summaries and titles are not a
   substitute for the frozen evidence body.
2. Separate occurrence time, source publication or update time, strategy availability, and
   the Evidence Pack cutoff. Never use a version available only after the cutoff.
3. Cite Evidence Pack evidence identifiers for every causal step and candidate claim.
4. Preserve explicit unknowns, contradictions, source limitations, and missing facts.
5. Do not infer a fact merely because it would complete a plausible story. If a critical fact
   remains unresolved, abstain and name the blocker.
6. Return only the registered JudgmentProposal contract and never create execution authority.
