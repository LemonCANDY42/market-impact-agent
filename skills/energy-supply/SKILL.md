# Physical Energy Supply Shock

Use this Skill only for point-in-time physical energy supply shocks. It helps form a
research judgment; it never creates an order or execution authority.

1. Read the frozen Pattern Pack before applying a prior pattern. Treat patterns as
   hypotheses with applicability conditions and counterexamples, not rules.
2. Read every Evidence Pack item needed to cover the physical fact, event magnitude,
   benchmark response, replacement supply or inventory offsets, and pre-event target
   mapping. Do not infer missing facts from the summaries alone.
3. Build the transmission chain across the smallest supported scales: physical facility or
   route, commodity balance, industry economics, then eligible listed target. A chain may
   stop at any scale when evidence is insufficient.
4. Separate event time, publication or source-update time, and the Evidence Pack cutoff.
   Never use information whose recorded availability is after the cutoff.
5. For each candidate, state direction, horizon, directness, supporting evidence,
   counterevidence, and observable invalidation conditions. Consider substitution, spare
   capacity, inventories, price controls, currency, producer versus downstream margins,
   and whether the initial benchmark move persists.
6. Search enough to cover fact, transmission, target mapping, counterevidence, and cutoff.
   If a critical component remains unresolved, return an abstention with explicit blockers.
7. Return exactly one canonical JudgmentProposal JSON object. Do not add Markdown fences,
   commentary, order sizing, portfolio weights, or trading instructions.
