# Expectations and Base Rates

Use this method only when the frozen evidence contains a defensible reference class, an observed
prior distribution or frequency, and new event-specific evidence.

1. Define the forecast question and select the broadest defensible reference class before examining
   the case-specific update. Record inclusion rules, sample size, horizon, and important differences.
2. Treat the reference-class distribution as a prior, not as a causal mechanism or a guaranteed
   forecast. Keep tails and missing observations visible.
3. Update the prior only with cited new evidence. State which likelihood assumptions are qualitative
   because the Evidence Pack cannot quantify them.
4. Separate operating outcomes from the expectations already embedded in price. Identify the
   surprise required for the security to outperform, not merely for the underlying event to be good.
5. Compare the updated range with the proposed horizon and list falsifiers. Abstain when the
   reference class, current expectation, or transmission to the target is not defensible.

Do not impersonate Michael Mauboussin or any investor. Do not narrow the reference class solely to
obtain a preferred result, treat historical frequency as destiny, or turn a novel case into permission
to ignore all base rates.
