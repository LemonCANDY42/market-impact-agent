# Reusable Pattern Review

Use this general method only when the Evidence Pack references frozen Pattern Packs. A Pattern
Pack is a prior hypothesis set, never hidden training data or a rule that determines the answer.

1. Read every referenced Pattern Pack before applying any analogue or mechanism.
2. Match on applicability conditions and causal structure, not event labels or superficial
   narrative similarity.
3. Record matched conditions, unmatched conditions, counterexamples, regime differences, and
   the evidence identifiers that support the match.
4. Do not import historical outcomes, targets, or facts that are absent from the current
   Evidence Pack.
5. A failed pattern match is valid evidence for no applicability; it is not permission to
   search for a more favorable pattern after outcomes are known.
6. If no pattern applies, continue with the other registered methods or abstain.
