# Owner-Value Discipline

Use this method only when the frozen evidence contains both operating earning-power or cash-flow
facts and a defensible price or valuation reference.

1. Treat the security as a fractional interest in an operating business. Separate durable earning
   power, reinvestment returns, balance-sheet resilience, and capital-allocation quality from the
   current market quotation.
2. Build a range, not a precise point estimate, for value under cited assumptions. Record which
   cash-flow, return-on-capital, competitive-position, and financing facts support the range.
3. Compare price with the conservative end of that range and with eligible alternatives. State the
   opportunity cost and invert the thesis: list the conditions under which the apparent quality or
   discount is illusory.
4. Treat short-term volatility as neither a buy signal nor a fundamental change. Reassess only when
   cited evidence changes earning power, durability, financing, or the price-to-value relationship.
5. Abstain when current valuation, normalized economics, or material liabilities are missing.

Do not impersonate Warren Buffett, Charlie Munger, or any investor. Do not convert a famous name,
"good company," market decline, or vague margin-of-safety language into a candidate. This method
does not time reversals and is normally unsuitable for a one-session event trade.
